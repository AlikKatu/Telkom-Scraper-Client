# TELKOM SCRAPER ENTERPRISE V3

## 🚀 CARA PAKAI UNTUK KARYAWAN (HANYA 3 LANGKAH)

1. Taruh file Excel target Anda di folder `input/`:
   - `daftar kota dan kabupaten.xlsx`
   - `keyword.xlsx`
2. Klik 2x file **`START_DASHBOARD.bat`**.
   *(Saat pertama kali dibuka, biarkan sistem memproses instalasi otomatis selama 1-2 menit)*.
3. Di dasbor:
   - Tekan **Menu 7** untuk mendeteksi Witel Anda.
   - Tekan **Menu 2** untuk mulai scraping.
   - Tekan **Menu 5** untuk mengambil hasil Excel di folder `exports/`.
